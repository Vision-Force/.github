Vision Force Studio is a one person fan made project

The org is new. Im Shrezee. Nobody here is paid, nothing here
is for sale, and no part of it is a product. It is a studio in the way a workshop is a
workshop, a place where the work is properly documentzed, named, and finished.

Work happens in public rather than being announced once it is done. That is the whole
point of this organisation

A volunteer is not a vendor. There is no support contract here, no roadmap promise, and
no date anyone is owed

Vision Force Studio runs a public development roadmap for Rocket Racing Revive. Sign in
with Google, Discord or GitHub on the [studio website](https://visionforceofficial.com)
to vote on what gets built next, post suggestions, and follow progress on [Vaelora
Velocity](https://visionforceofficial.com/documentation/vaelora-velocity) and eventually [LUX3](https://visionforceofficial.com/documentation/lux3). The [service status page](https://status.visionforceofficial.com)
says plainly whether the services are up

> [!TIP]
> Voting is the fastest way to help without writing a line of code. It costs a sign in
> and tells the studio which of two roughly equal jobs to do first

Rocket Racing Revive is the name for those halves together. Vaelora Velocity is the
standalone Unreal Engine 5 game. LUX3 is the roughly 50 sunset Rocket Racing tracks,
recreated in UEFN

Vaelora Velocity began inside another reality, actually tied to Fortnite's lore, its
destabilisations and its metaverse. The Reality Cross is the moment it left the Fortnite
Loop.

Three names, one line each. more details on the website
and in the roadmap, where it can be argued with and voted on.

Rocket Racing Reborn, codename Meridian, is the reason this organisation exists actually

It is an original re implementation of the EPIC network services that an archived Fortnite
build expects to talk to. so that an old build can
be played privately again by the people who still love to

It is early and in development. Nothing about it is finished, and no feature of it
is shipped yet

It is the server side only:
the endpoints an archived client tries to reach

There is no download here yet

<a id="method" name="method"></a>

<img src="https://raw.githubusercontent.com/Vision-Force/.github/main/profile/assets/section-inside.svg" width="100%" alt="How we work: the method" />

Everything is written from scratch. Where a behaviour has to match something that already
exists, it is reconstructed as original code and the reasoning is recorded alongside it.
That is slower than the alternative. It is also the only version of this worth building.

The roadmap is public and votes decide priority. Sign in on the website, vote on what gets
built next, and post a suggestion if the thing you want is missing. The list is kept short
on purpose, so a single vote actually moves it.

Progress is posted as it happens, including the parts that do not work yet. A volunteer
studio has no release schedule to protect, so there is no reason to only show the finished
half.

Scope is chosen to be finishable by one person. A smaller thing that exists beats a larger
thing that is always nearly ready, so the plan is trimmed rather than the standard.

first. The roadmap and the vote live on the website. The status page says plainly whether

legal. Those get read first and answered directly.

YouTube carries the devlogs. Neither is a support
channel, so a question asked there will be answered slower than the same question asked
on Discord.
